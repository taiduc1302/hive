# Source policy

## Authority order

1. Official model/API documentation.
2. Official provider release notes/changelogs.
3. Official product help documentation.
4. Provider-authored cookbooks/engineering posts.
5. Community sources only as discovery leads; label unverified until confirmed.

## Freshness rule

Never rely on the bundled snapshot alone for “latest/current/today/new/best now” requests. Re-check official sources. A changed webpage fingerprint is a review trigger, not proof by itself.
